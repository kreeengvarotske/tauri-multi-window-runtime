# Tauri Multi-Window Runtime

A typed runtime framework for Tauri v2 multi-window desktop applications, with a TypeScript SDK and a Runtime Lab demonstration app.

## Documentation

- [Frontend and TypeScript SDK](docs/frontend.md)
- [Frontend/backend IPC contract](docs/frontend-backend-contract.md)
- [Automated checks and benchmark procedure](docs/automated-benchmarks.md)

The Runtime Lab demo exercises Rust Core task coalescing, a shared metadata cache, diagnostics, and two-window request handling. Benchmark conclusions should be based on repeated Release-build measurements rather than a single run.
